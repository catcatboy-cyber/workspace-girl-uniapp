# Crush Master UI 重设计方案 · 5 套视觉风格

**日期**：2026-07-04
**目标**：针对不同性向用户群体的审美偏好，提供 5 套完整 UI 风格方案
**现状**：Campus Pop（粗黑边框 brutalist 风，偏 Gen-Z 女性向杂志感）

---

## 用户群体分析

Crush Master 的核心功能是"记录暧昧互动 → AI 分析对方信号 → 给出下一步建议"。用户群体按性向可分为：

| 群体 | 核心诉求 | 审美偏好关键词 |
|------|---------|---------------|
| 直女（当前主力） | 分析男生信号、防渣、确认心意 | 温柔、安全感、少女心但不幼稚、高级感 |
| 直男 | 看懂女生暗示、找最优策略 | 简洁克制、数据化、工具感、暗色 |
| 女同 | 识别对方好感、避免直弯错判 | 柔和中性、不过度粉、细腻自然 |
| 男同 | 判断对方态度、社交信号解读 | 质感极简、都市感、精致暗调 |
| 双性恋/泛性恋 | 多元关系信号、灵活不设限 | 流动色彩、包容感、不贴标签 |

## 方案 A：「奶茶絮语」Milk Tea Whisper

**面向**：直女（18-25 大学生/初入职场）
**关键词**：温柔治愈 · 奶茶色系 · 手账感 · 闺蜜私语

### 色板

```
背景        #FDF6F0  奶油白（比现在的 #FFFDF5 更暖偏粉）
卡片        #FFFFFF
主色        #D4A574  焦糖奶茶（替代当前黑色边框）
强调        #E8A0BF  玫瑰粉（替代当前珊瑚红）
积极        #A8D8B9  薄荷奶绿
警告        #F2A6A6  柔粉红
文字主      #3D2C1E  深巧克力
文字辅      #8B7355  卡布奇诺灰
标签底      #FEE8D6  浅杏
```

### 形态语言

| 属性 | 值 |
|------|---|
| 圆角 | 16-24rpx（柔和但不过圆） |
| 边框 | 1.5rpx solid rgba(212,165,116,0.3)（极淡焦糖线） |
| 阴影 | 0 8rpx 24rpx rgba(212,165,116,0.08)（温暖漫射） |
| 字重 | 标题 600，正文 400（不再用 800-900 超粗） |
| 间距 | 宽松，卡片内 padding 36rpx |
| 动效 | 淡入 + 轻微上浮，ease-out，不旋转 |

### 组件差异

- **Hero 区域**：不再用纯色块 + 旋转，改为带柔和渐变的圆角卡片 + 手写体 tagline
- **信号卡片**：白底卡片，左侧 4rpx 语义色条（不是 12rpx 粗条），轻阴影
- **按钮**：圆角胶囊形，主色填充 + 白色文字，无硬边框
- **标签**：pill 形状，浅杏底 + 焦糖文字
- **图标风格**：线性手绘风（类似 notion/bear app 图标）
- **宠物形象**：可保留，但气泡框改为圆角 + 奶白底

### 情绪板描述

想象你在一个温暖的下午，坐在咖啡厅角落，翻开一本手帐记录今天和他的互动。页面像奶茶一样温润，文字像闺蜜在耳边轻声分析。没有压迫感，没有刺眼的颜色——只有温柔的确认："你没有想多，他确实有意思。"

## 方案 B：「深夜电台」Midnight Station

**面向**：直男（20-30 程序员/理工科/职场男性）
**关键词**：暗色沉浸 · 数据仪表盘 · 克制理性 · 工具感

```
强调        #F78166  暖橙（关键数据高亮）
积极        #3FB950  代码绿
警告        #F85149  警报红
文字主      #E6EDF3  冷白
文字辅      #7D8590  烟灰
标签底      #21262D  深灰卡片
边框        #30363D  微光边
```

### 形态语言

| 属性 | 值 |
|------|---|
| 圆角 | 8-12rpx（小圆角，结构感） |
| 边框 | 1rpx solid #30363D（暗线分隔） |
| 阴影 | 无外阴影（靠边框和背景层次区分） |
| 字重 | 标题 500-600（不夸张），正文 400 |
| 间距 | 紧凑高效，信息密度高 |
| 字体 | 数据区用等宽字体（tabular-nums），正文用系统无衬线 |
| 动效 | 极少动效，数据变化用数字滚动，不要弹跳/粒子 |

### 组件差异

- **Hero 区域**：去掉。改为顶部 KPI 仪表条（意向分 / 风险分 / 趋势箭头），类似股票 app
- **信号卡片**：暗底卡片，紧凑行间距，左侧用 2rpx 竖色条标注语义
- **按钮**：ghost 按钮（透明底 + 蓝色边框），主操作用蓝色填充
- **标签**：小字号 + 暗底圆角 pill，颜色极淡
- **评分展示**：大号数字 + 进度环/条形图，类似 dashboard
- **措辞调整**："TA 的信号"→"对方信号强度"，"有戏吗"→"意向指数"

### 情绪板描述

凌晨两点，你打开手机看一眼今天和她的对话分析。界面像一个私人数据面板——没有花里胡哨的装饰，只有冷静的蓝色数字和清晰的趋势线。意向指数 72，较上周 +8。你知道该怎么做了。关掉屏幕，睡觉。

| 属性 | 值 |
|------|---|

### 组件差异

- **Hero 区域**：全幅渐变卡片（紫→青），文字白色，圆角 32rpx，像一颗流动的宝石
- **信号卡片**：白底 + 底部 3rpx 渐变色条（不是左侧），无硬边框
- **按钮**：渐变填充 + 白字，形状为大圆角胶囊
- **标签**：浅紫底 / 浅青底，交替使用，体现多元
- **状态指示**：不用单一色条，而是根据语义切换渐变色系（积极=青系渐变，警告=橙红渐变）
- **图标**：双色 duotone 风格（一浅一深），不用单色线条
- **措辞**：完全去性别标签，"你的心动对象"/"你关注的人"，支持多 crush 不分性别

### 情绪板描述

打开 app 的那一刻，屏幕像一块棱镜在光线中转动——紫色流向青色，橙色悄然浮现。这里不问你喜欢的是谁，不给你贴标签，只关心你们之间的化学反应。每一次分析结果都用独特的渐变呈现心情：他今天的态度是一片暖橙，而昨天更偏冷青。一切都在流动。

## 实施建议

### 推荐路径

1. **如果用户群体不变**（仍以直女为主）：选 **A 奶茶絮语** 作为新默认主题，保留当前 Campus Pop 作为可选
2. **如果想拓展用户**：实现主题系统（已有基础），增加 B/D/E 作为可选主题
3. **如果走多元包容路线**：选 **E 棱镜漫射** 作为默认——它对所有性向都友好，不贴标签

### 技术改动量评估

当前项目已有主题切换机制（`theme.ts` + CSS Variables），增加新主题的成本主要在：

| 改动 | 工作量 | 说明 |
|------|--------|------|
| 新增 `themeOptions` 条目 | 小 | 只改 `theme.ts` 一个文件 |
| 新增 styleSheet 形态 | 小 | 在 `styleSheets` 对象中加条目 |
| `.v2-mode` 样式适配 | **大** | 当前所有样式硬编码了 #111 边框/offset shadow，需要改为 CSS Variable |
| 暗色主题适配 | 中 | B/D 方案需要反色处理，当前 .v2-mode 全是白底 |
| 措辞/文案系统 | 中 | 如果要按主题切换措辞，需要抽取文案层 |
| 图标/插图替换 | 中 | 如果要匹配不同风格的图标体系 |

### 最小 MVP

不改代码架构，最快见效的方式：

1. 将 `.v2-mode` 中的硬编码颜色（`#111`、`#FFD93D`、`#FF6B6B`）替换为 CSS Variable
2. 将 `box-shadow: Xrpx Xrpx 0 #111` 替换为 `var(--shadow-card)`
3. 将 `border: 3rpx solid #111` 替换为 `var(--card-border)`
4. 在 `theme.ts` 中新增方案的色板和形态参数
5. 用户在"我"页面的主题设置切换

这样 5 套主题可以共存，用户自选。

## 附录：当前 Campus Pop 的问题

| 问题 | 表现 | 影响 |
|------|------|------|
| 过于强势 | 900 字重 + 粗黑边框 + offset shadow 无处不在 | 长时间使用视觉疲劳 |
| 风格单一 | 只有一种 brutalist 表达 | 非 Gen-Z 女性用户觉得"太吵" |
| 黑色主导 | #111 是结构色也是文字色也是边框色 | 层次感不足，所有元素同等"重" |
| 不适合暗色 | 硬编码白底+黑框，无法适配 dark mode | 夜间使用刺眼 |
| 情感色过少 | 只有珊瑚红和薄荷绿两个语义色 | 状态表达单调 |
| 排版密度不均 | Hero 区很大但信息少，记录区信息密集 | 阅读节奏不流畅 |
