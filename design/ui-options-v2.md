# 微信小程序 UI 方案 V2：更好玩版本

边界：这是设计稿，不改生产代码。

## 关于登录画像分流

可以做，但它不再是“纯 UI 改版”，而是 onboarding + 用户画像 + 主题分流逻辑。

建议做法：
- 登录后第一次进入，展示 1 个轻量画像页。
- 字段：性别、年龄段、当前身份、记录关系类型、星座/属相可选。
- 不建议强制填写属相/星座，年轻人会觉得好玩，但强制会增加流失。
- 年龄小于 18 岁时，不进入“恋爱/泡妞”语境，只进入“同学/朋友关系记录”语境。

分流规则建议：
- 男大学生 + 恋爱/暧昧：默认 `Crush Arcade`
- 女大学生 + 恋爱/暧昧：默认 `Soft Diary Pop`
- 小于 18 岁 + 友谊/同学：默认 `Campus Sticker`
- 理性分析偏好：可手动切到 `Signal Game`

注意：
- 未成年人场景不要使用“泡妞、暧昧推进、追人”等文案。
- 改成“同学关系、朋友互动、沟通记录、边界感提醒”。
- 这既是产品伦理，也是审核风险控制。

## V2 设计方向

这次重点不是“好看”，而是“年轻人觉得好玩、想打开、想继续记”。

### E. Crush Arcade

定位：恋爱信号小游戏，不是严肃报告。

视觉关键词：
- 游戏机 UI、能量条、等级、任务卡
- 霓虹粉 + 电光蓝 + 奶油黑
- 卡片像关卡，快速记录像“今日任务”
- 趋势数据像能量面板

页面变化：
- 首页标题：`今日恋爱信号`
- 快速记录：像输入一条“事件弹幕”
- 即时反馈：像过关结算，显示 `意向 +8 / 风险 -3 / 证据 E4`
- 关系主页：像角色档案 + 信号面板

适合：
- 男生、愿意把关系分析当游戏玩的用户
- 想做传播和留存

风险：
- 不能太游戏化，否则会降低严肃建议的可信度

### F. Campus Sticker

定位：校园贴纸板，像宿舍门口的关系便签墙。

视觉关键词：
- 手绘边框、贴纸、胶带、便利贴
- 暖纸底、红蓝马克笔、黄色便签
- 卡片轻微旋转，但核心按钮保持稳定
- 原“阶段观察点”改为“后续验证重点”，并只保留一个核心卡片：`最该看`

页面变化：
- 首页像“今天发生了啥？”
- 时间轴像一串贴在墙上的便签
- 关系主页像一张对象观察板

适合：
- 小于 18 岁友谊场景
- 校园同学关系、朋友关系
- 女生/男生都能接受

风险：
- 手绘风不能太幼稚，文字必须足够清楚

### G. Bubble Chat Lab

定位：聊天气泡式 AI 恋爱助手。

视觉关键词：
- 大量气泡模块，而不是传统卡片
- AI 反馈像聊天回复
- 趋势数据像聊天里的小组件
- 视觉主色：薄荷绿 + 玫瑰粉 + 浅蓝

页面变化：
- 首页快速记录就是大输入框 + 气泡反馈
- 即时反馈像 AI 发来的“解读消息”
- 关系主页像聊天置顶信息：画像、状态、趋势
- 时间轴像聊天记录，但仍按真实事件排序

适合：
- 女大学生、日常聊天重度用户
- 想降低 AI 工具感

风险：
- 信息很多时可能显得松散，需要强分组

### H. Signal Game

定位：更年轻的数据游戏化，不是传统 dashboard。

视觉关键词：
- 任务徽章、进度环、信号雷达、状态芯片
- 黑白底 + 高亮绿/粉/蓝
- 数据很多，但呈现成“游戏 HUD”
- 关系主页重点显示“当前关卡/信号值/风险警报”

页面变化：
- 首页：当前对象 = 当前任务
- 趋势数据：信号值、风险值、稳定度、证据量
- 后续验证重点：只保留一个 `最该看` 卡片，下面接 `依据证据`

## 后续验证重点的新结构

只保留三部分：

1. 标题：`后续验证重点`
2. 卡片 1：`最该看：他/她会不会继续主动确认下一步`
3. 依据证据：列出 1-3 条导致系统提出这个验证重点的真实事件

去掉：
- `主要观察点`
- `次观察点`
- 多张并列观察卡
- 大段解释文案

设计意图：
- 用户不需要同时盯很多东西，只需要知道下一次最该验证什么。
- `最该看` 是行动前的观察焦点，不是结论。
- `依据证据` 负责建立信任：让用户知道这个验证重点来自哪些真实记录。

推荐文案：
- 标题：`后续验证重点`
- 卡片标题：`最该看`
- 卡片内容：`他是否会主动确认下次见面，而不是只停留在口头热情。`
- 依据标题：`依据证据`
- 评估历史：像战报列表

适合：
- 男女通用
- 喜欢理性判断但又不想太严肃的大学生

风险：
- 需要文案更克制，避免像真的“操控关系”

## 我的 V2 推荐

如果目标是“年轻人觉得好玩”，我建议：

默认主风格：`G. Bubble Chat Lab`

原因：
- 大学生恋爱/暧昧的核心行为本来就是聊天。
- 用聊天气泡做 AI 反馈，用户理解成本最低。
- 它比纯粉色更自然，比游戏机更不冒犯，比手账更有互动感。
- 男女都能接受，女生会觉得亲近，男生也不会觉得太粉。

第二选择：`E. Crush Arcade`

适合你想做得更抓眼、更容易传播时使用。

未成年人/友谊模式：`F. Campus Sticker`

不进入恋爱语境，改成朋友互动记录。
