# 2026-06-29 工作日志

## 修复 chooseImage 隐私协议声明缺失

### 问题
"今日"页面添加附件时报错：`chooseImage:fail api scope is not declared in the privacy agreement`

### 根因
`privacy.json` 使用了非标准格式（`description`/`details`），缺少微信要求的 `privacy_interface` 字段声明。微信隐私保护机制启用后（`__usePrivacyCheck__: true`），所有隐私 API 调用前必须在隐私协议中声明对应接口。

### 改动
1. **`privacy.json`** — 重写为微信标准格式，添加 `desc`/`owner`/`permission`/`privacy_interface` 字段，声明 3 个隐私接口：
   - `chooseImage` — 选择图片作为附件/头像/自定义形象
   - `saveImageToPhotosAlbum` — 保存分享图到相册
   - `record` — 语音输入录音
2. **`src/pages.json`** — `permission` 字段新增 `scope.writePhotosAlbum` 权限声明
3. **`src/pages/custom-pet/custom-pet.vue`** — `pickImage()` 添加 `requirePrivacyAuthorize` 隐私授权检查
4. **`src/pages/taohua/taohua.vue`** — `saveShareImage()` 添加 `requirePrivacyAuthorize` 隐私授权检查
5. **`dist/build/mp-weixin/privacy.json`** + **`app.json`** — 同步更新构建产物
6. **`dist/dev/mp-weixin/privacy.json`** — 创建隐私配置文件

### 第三轮修复（13:48）— app.json permission scope 非法

#### 报错
```
无效的 app.json permission["scope.record"]、app.json permission["scope.writePhotosAlbum"]
```

#### 根因
`app.json` 的 `permission` 字段**只接受白名单内的 scope**（userLocation / userLocationBackground / address / invoiceTitle / invoice 等）。
`scope.record` 和 `scope.writePhotosAlbum` 不在白名单中 — 它们属于**隐私接口**，必须通过 `privacy.json` 的 `privacy_interface` 声明，`app.json.permission` 不能写。

#### 改动
1. **`vite.config.js`** — `patchMpWeixin()` 改为：只补丁 `__usePrivacyCheck__`，不再写入 `permission` 字段；如产物中有 `permission` 则主动 `delete`
2. **`src/pages.json`** — 删除 `permission` 整个块

#### 验证
- `npm run build:mp-weixin` 成功
- `dist/build/mp-weixin/app.json` 末尾仅剩 `__usePrivacyCheck__: true`，无 `permission` 字段
- `dist/build/mp-weixin/privacy.json` 中的 `permission` 数组（含 `scope.record` / `scope.writePhotosAlbum`）是合法位置
